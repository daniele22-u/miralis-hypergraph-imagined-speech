### 6. EEG_07c — Analisi Esplorativa dei Grafi (COMPLETATO ✓)

Creato `EEG_07c_graph_exploratory.ipynb` su suggerimento del supervisore (Francesco):
analisi statistica pre-training per capire se la struttura del grafo porta
informazioni discriminative sulle categorie semantiche.

**6 analisi implementate**:

1. **Matrici di connettività per categoria**: PCC medio per cluster semantico,
   differenza da media globale (evidenzia pattern specifici per categoria)

2. **Edge discriminativi (ANOVA)**: F-statistic one-way per ogni coppia di elettrodi;
   top-20 edge più discriminativi su layout elettrodico; topomap discriminabilità nodi

3. **t-SNE / PCA sui feature del grafo**: vettore grafo appiattito (1711 dim),
   proiezione 2D colorata per categoria; evidenzia se il grafo separa semanticamente

4. **Distanza intra vs inter-categoria**: per ogni soggetto, confronto distanza
   media tra grafi stessa vs diversa categoria (test se grafo separa le categorie)

5. **Confronto metodi PCC vs PLV vs wPLI**: F-score medio degli edge per metodo;
   box plot + bar chart; identifica metodo più discriminativo

6. **Consistenza cross-soggetto**: correlazione inter-soggetto dei vettori F-score;
   heatmap 70×70 + topomap media (test se pattern discriminativi sono universali)
