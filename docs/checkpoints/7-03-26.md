# Checkpoint — work completed today

## 1. Construction of EEG subject tensors

Today we finalized the creation of the EEG feature tensors at subject level, starting from the precomputed 40 features per electrode.

### Two main tensor formats were built

#### A. Aggregated epoch representation

For each trial, the full EEG epoch was treated as a single segment and the 40 features were computed over the whole signal.

- shape per subject: `(n_trials, 59, 40)`
- where:
  - 59 = retained EEG channels
  - 40 = extracted features per channel

This representation removes the explicit temporal subdivision of the trial.

#### B. Time-resolved representation

For each trial, the EEG epoch was divided into **5 temporal windows**, and the same 40 features were computed separately in each window.

- shape per subject: `(n_trials, 5, 59, 40)`

This preserves a coarse temporal structure inside the trial.

### Channel handling

The original `.locs` file contained 61 channels, but `A1` and `A2` were excluded because they overlap with `Cz` in the montage and act as reference channels.  
All tensors were therefore rebuilt using **59 valid channels**.

## 3. TensorFlow Projector exports

We then created TSV exports for low-dimensional embedding analysis in TensorFlow Projector.

### Three projector modes were prepared

#### A. Aggregated trial representation

- one point = one full trial
- flatten shape: `(n_trials, 59×40)`

#### B. Time-concatenated trial representation

- one point = one full trial
- the 5 windows are concatenated into one single vector
- flatten shape: `(n_trials, 5×59×40)`

#### C. Window-level representation

- one point = one temporal window
- flatten shape: `(n_trials×5, 59×40)`

We also created code to merge two subjects into the same projector dataset, so that subject-level structure could be directly visualized.

---

## 4. Embedding analysis (t-SNE / UMAP / PCA)

Using the projector, we explored the three representations through low-dimensional embedding methods.

### Main observations

#### A. Word-level structure

When searching for individual words (e.g. *guerra*, *morte*), the corresponding trials did **not** form compact clusters.

This suggests that:

- the lexical content is not naturally separated in the raw feature space
- imagined speech trials are highly variable across repetitions

#### B. Subject-level structure

When two subjects were merged and colored by `source_subject`, the embeddings showed a **very strong separation by subject**.

This was one of the clearest results of the day:

- EEG feature embeddings are strongly **subject-specific**
- inter-subject variability dominates the feature geometry much more than the imagined word label

#### C. Session / epoch effects

Coloring by:

- `session_id`
- `epoch_idx`

did **not** explain the main structure of the manifold.

So the dominant variability does **not** appear to come from:

- session drift
- progressive temporal order of the trials

#### D. Geometry of the manifold

The aggregated and time-resolved embeddings often showed:

- curved manifolds
- ring-like or horseshoe-like structures
- continuous low-dimensional organization

This is consistent with the idea that EEG trials occupy a **continuous neural manifold**, rather than a set of discrete lexical clusters.

## 5. First baseline classification experiments

We then started testing simple classifiers on the **110-word subject-independent imagined speech task**.

### First reduced baselines

To start conservatively, we did **not** use the full tensors directly.  
Instead, we compressed them before classification.

#### Aggregated reduced baseline

Starting from `(59, 40)`, we averaged over channels:

- input to classifier: `(40,)`

#### Time reduced baseline

Starting from `(5, 59, 40)`, we averaged over channels in each window and concatenated the result:

- input to classifier: `(5×40) = (200,)`

---

## 6. Subject-independent logistic regression

We compared:

- aggregated reduced representation `(40,)`
- time-concatenated reduced representation `(200,)`

### Result

Both models performed at approximately **chance level** on the 110-word task.

This means that:

- a simple linear model is not sufficient
- reduced channel-averaged representations do not support subject-independent word decoding

---

## 7. Subject-specific MLP (reduced representation)

We then tested a small MLP on a **single subject**, still using the reduced representations:

- aggregated reduced `(40,)`
- time reduced `(200,)`

A fixed split per word was used:

- 3 trials for training
- 1 trial for validation
- 1 trial for test

### Result

Performance remained essentially at **chance level**.

This is important because it means that, with this compressed formulation:

- the problem is not only subject transfer
- even within a single subject, the representation is too weak for 110-word decoding

---

## 8. MLP on full flattened representations

To verify whether the poor performance of the first baselines was mainly caused by the aggressive averaging across channels, we repeated the experiments using the **full flattened tensors**, without channel averaging.

Two full vector representations were tested.

### Aggregated full representation

Each trial was flattened from:

`(59, 40) → 2360` features

### Time-resolved full representation

Each trial was flattened from:

`(5, 59, 40) → 11800` features

This preserves the full spatial structure of the extracted features, and in the time-resolved case also preserves the temporal windows, although both representations are still treated as plain vectors.

### Results

#### Subject-specific

The same split per word was used:

- 3 trials for training
- 1 trial for validation
- 1 trial for test

Even with the **full flattened representations**, performance remained essentially **at chance level**.

#### Subject-independent

Training and testing were performed with a **group split over subjects**.

Again, both full representations remained essentially **at chance level** on the 110-word classification task.

### Interpretation

These results indicate that simply increasing the dimensionality of the input vector is not sufficient to recover discriminative information for imagined word decoding.

In other words:

- the poor baseline performance is **not explained only by channel averaging**
- even when preserving the full feature tensor, **vector-based models still fail**
- this suggests that the useful information, if present, is not easily accessible through a simple flatten-and-classify strategy

## 9. Feature-level statistical analysis

To further understand the behavior of the extracted EEG features, we performed a feature-wise statistical analysis across the entire dataset.

The goal was to evaluate whether the computed features exhibit statistically significant differences with respect to:

- **word identity** (`label_id`)
- **subject identity** (`subject_id`)
- **recording session** (`session_id`)

### Method

Starting from the **aggregated representation** `(59, 40)` for each trial, we built a trial-level feature table by computing:

- **mean across channels** for each feature  
- **standard deviation across channels** for each feature

This resulted in **80 scalar descriptors per trial**:

- `mean__feature`
- `std__feature`

For each descriptor we performed:

- **Kruskal–Wallis tests** across groups  
- **Benjamini–Hochberg FDR correction** for multiple comparisons  
- **epsilon-squared (ε²)** as a non-parametric effect size

### Results

The statistical analysis revealed a clear pattern.

#### Word effect

No clear discriminative effect of the extracted aggregated features was found with respect to the **110 imagined words**.

Overall, word-related effect sizes were extremely small, indicating that simple aggregated feature statistics do not preserve lexical information in a directly usable form.

#### Subject effect

In contrast, the features showed a **strong dependence on subject identity**.

This confirms that the extracted feature space is largely dominated by **inter-subject variability**, which is consistent with the projector visualizations where trials clustered primarily by subject rather than by word.

#### Session effect

The session-related effect was much weaker than the subject effect and did not explain the dominant geometry of the embedding space.

This suggests that the main source of structure is not session drift, but rather subject-specific variability.

### Interpretation

This statistical analysis reinforces the main conclusion of the embedding and baseline experiments:

- the current feature space is dominated by **subject identity**
- simple aggregated feature statistics do **not** capture word-level discriminative structure
- lexical information, if present, is likely encoded in more complex **spatial**, **temporal**, or **relational** patterns that are lost when the signal is reduced to simple vectors or channel-aggregated summaries

## 10. Interpretation of today’s results

Taken together, today's experiments indicate that:

1. **Channel averaging is not the only limiting factor**  
   Even when preserving the full spatial information, vector-based models still fail to decode the 110-word task.

2. **The 110-word imagined speech problem is extremely challenging**  
   Especially considering the small number of trials per word.

3. **Inter-subject variability dominates the feature space**  
   This was clearly visible in the projector embeddings, where trials cluster primarily by subject rather than by word.

4. **Vector-based baselines appear insufficient**  
   Both linear models and shallow MLPs on reduced and full flattened representations remain at chance level.

5. **The spatial and relational structure of EEG signals is likely crucial**  
   Treating the signal as a simple vector ignores meaningful relationships between electrodes.

---

## 11. Next methodological direction

Given these results, the next step is to explore models that explicitly preserve the **structure of the EEG data**, instead of flattening it.

In particular:

- **Graph-based representations**
  - nodes = EEG electrodes
  - node features = extracted features per channel
  - edges = spatial proximity or functional connectivity

Such models can naturally encode:

- spatial relationships between electrodes
- structured signal propagation over the scalp
- potentially temporal dynamics across windows

This motivates the transition toward **graph neural network baselines**, and more specifically toward the planned **hypergraph neural network** formulation.
